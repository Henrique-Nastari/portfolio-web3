# 🌐 Portfólio Web3 — Henrique

> Site portfólio pessoal multidisciplinar: InfoSec · Fullstack Developer · Data Science

## Stack

- **Next.js 15** (App Router, SSG)
- **TypeScript 5**
- **Tailwind CSS v4**
- **Framer Motion 11**
- **Three.js + @react-three/fiber**
- **MDX** (projetos e blog)
- **Resend** (formulário de contato gratuito)
- **Vercel** (deploy gratuito)

## Começando

```bash
npm install
npm run dev
```

## Variáveis de Ambiente

Copie `.env.example` para `.env.local` e preencha:

```bash
cp .env.example .env.local
```

## Estrutura

Ver [PLANO_DE_ACAO.md](./PLANO_DE_ACAO.md) para arquitetura completa.

## Deploy

Push para `main` → deploy automático na Vercel.
